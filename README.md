# nano_url (Back-end) 🚀

> API de back-end para o **nano_url**, um site de encurtamento de links desenvolvido em Laravel.

---

## 📋 Pré-requisitos

Certifique-se de ter as seguintes ferramentas instaladas em sua máquina:
* [PHP](https://www.php.net/) (versão compatível com o Laravel)
* [Composer](https://getcomposer.org/)
* [Git](https://git-scm.com/)
* [MySQL](https://www.mysql.com/) (ou utilize o XAMPP)

---
